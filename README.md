# GreenHub

Strona internetowa fundacji Green Hub Foundation.

## Uruchomienie

Projekt jest statyczną stroną HTML/CSS/JS. Można ją otworzyć bezpośrednio przez `index.html` albo opublikować przez GitHub Pages.

## Zawartość

- responsywna strona główna z komunikatem „Strona w budowie”;
- logo Green Hub Foundation wykorzystane z pliku znajdującego się w repozytorium;
- nawigacja: O fundacji, Obszary działań, Projekty, Aktualności i Kontakt;
- sekcja kontaktowa z dwiema przykładowymi osobami;
- przykładowe treści związane z rozwojem społeczności, ekologią i inżynierią środowiskową.

Dane kontaktowe i teksty są tymczasowe i powinny zostać zastąpione właściwymi informacjami przed publikacją.
